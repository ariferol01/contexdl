login.ctxdl
Verbose Prompt
"I need you to write the logic for the user login flow. First, please make sure to validate the form inputs by checking if the email format is correct and the password meets our security requirements. If the validation passes and the backend returns a success response, I want you to connect to the database and create a new active session for the user. After that, please render a green success toast notification in the UI that says 'Welcome back!'. Finally, use our UX animation library to trigger a 'slideOutLeft' transition on the login form component so it smoothly exits the screen. However, if the validation fails or the backend throws an error, please display a red error toast message, and also apply a CSS 'shake' animation to the form container to indicate to the user that something went wrong."
VS
Multi-layer ContextDL Expression
user.login ? form.validate -> success: db.session.start -> ui.toast.success -> ux.form.animate(slideOutLeft) | fail: ui.toast.error -> ux.form.animate(shake)
OR
user.login: validate: form on success: db.session.start ui.toast.success ux.form.animate(slideOutLeft) on fail: ui.toast.error ux.form.animate(shake)
